Make Claude Code talk back.

Natural spoken replies for Claude Code, powered by the open-source Kokoro voice model and built on Claude Code's mod system. No API key, no tokens, no bill, and your text never leaves your machine. Press play on any voice below.

Any other voice, any other language

These are the voices that ship with Kokoro, not a limit. Any Kokoro-compatible voice works: drop a voice file in your voices folder, or point CLAUDIO_TTS_MODEL and CLAUDIO_TTS_VOICES at another Kokoro model and voices pack. And a voice can read any of 140 languages with /tts lang <code> (with an accent where it has no native voice), for example /tts lang de for German. Details in the voices guide.

/tts voice bf_emma
/tts speed 0.9
/tts lang de          # German through the current voice, with an accent
/tts lang auto        # back to the voice's own language
